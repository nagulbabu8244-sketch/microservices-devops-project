# User Service

## Overview
The User Service is one of the three microservices in this project.

## Purpose
- Manage user-related operations.
- Provide the User Service component for the microservices application.
- Run as an independent Docker container.

## DevOps Configuration
- Source Control: Git and GitHub
- Containerization: Docker
- CI/CD: Jenkins
- Orchestration: Kubernetes

## Deployment
The User Service Docker configuration and Kubernetes deployment
manifest are maintained separately in this repository.
